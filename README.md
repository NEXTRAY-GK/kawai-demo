## 作りの考え方

**プレスの動きは3つ ── 送る（横）・叩く（縦）・抜ける（奥）。ページの動きも、その3つだけで組んである。**それ以外の動きは足していない。

- **写真は断ち切る。**画面の端まで出して、箱に入れない
- **見出しは大きく振る。本文は小さく置く。**中間の大きさを作らない
- **橙は「絞る」「電話」「数字の単位」だけ。**それ以外は鋼の灰
- **罫線を引かない。**段差は地の明るさで作る
- **見出しの上に英字の小ラベルを置かない。**画面の端に縦組みで立てる（`.side`）

### 動き

| どこ | 何が起きるか |
|---|---|
| ヒーロー | 写真が奥へ引く（スクロールに対して0.14倍で動く） |
| 送り帯 | 材料名が左へ流れ続ける。**スクロールすると速まる** |
| 3つの強み | 写真が画面端まで断ち切られ、左右交互に出る。下からマスクで押し出す |
| 数字 | **スクロールした量だけ数字が走る。**一度満ちたら戻さない |
| 設備 | **縦スクロールで横に流れる**（sticky＋translateX）。9段階のトン数を横に送る |
| 材料 | 6種を段違いに置く。ホバーで持ち上がる |

**⚠️ 動きが無くても成立するように組んである。**横送りは既定が縦積みで、JSが動いて、かつ「視差効果を減らす」がOFFのときだけ横送りに切り替わる（`html.rail-on`）。
**ここを逆にすると、JSが死んだ端末や `prefers-reduced-motion` がONの端末で、カードが画面の外に取り残されて真っ黒な画面になる。**2026-09-03に一度その状態を作って、直した。

## 直すときは `_build/` を触る

**HTMLを直接いじらない。**次のビルドで消える。
