## 作りの考え方

**「鋼と紙」。**色で飾らない。段差は罫線ではなく、墨（`#0E1113`）と紙（`#EDEDE8`）の入れ替えで作る。

- **写真は箱に入れない。**画面の端まで断ち切る（`.bleed-l` `.bleed-r`、強みの積みは左右交互）
- **見出しは大きく振る。本文は小さく置く。**中間の大きさを作らない
- **囲まない。**数字も材料も設備も、細い罫線1本で区切るだけ
- **節の標識は和文。**画面の左端に縦組みで立てる（`.side`、1440px以上のときだけ）
- **和文の行長は `em` で決める。**`ch` は「0」の幅で、全角の6割しかない。1行28〜34字に収める

### 動き

| どこ | 何が起きるか |
|---|---|

**⚠️ 1画面で同時に動く物は2つまで。**だから方眼は**墨の面にだけ**敷いてある。表紙（写真が奥へ引く）と、写真の上には出さない。
**⚠️ このMacは「視差効果を減らす」がON。**その端末では方眼は追わず、薄く全面に敷いたまま止まる。**代表の画面でも同じなら、カーソル追従は見えない**（システム設定 → アクセシビリティ → 画面）。**止めた絵で成立することは実測した。**

**⚠️ 動きが無くても成立するように組んである。**`prefers-reduced-motion` がONなら、全部止めて静止で読める。
**⚠️ 送り帯を rAF（requestAnimationFrame）で毎フレーム動かしてはいけない。**2026-09-03に一度やって、描画が張り付いて画面が真っ白になった。CSSのanimationに戻した。
